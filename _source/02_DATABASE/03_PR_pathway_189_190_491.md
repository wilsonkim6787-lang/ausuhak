## ⚠️ 핵심 정보 (2026 기준 — 최신 검증)

### 비자 관련
- 학생비자 처리: 평균 4-8주 (빠르면 1-2주, 늦으면 12주+)
- **학생비자(500) 신청비: 2,000 AUD** (2025.7부터, 이전 1,600)
- **485 졸업비자 신청비: 4,600 AUD** (2026.3.1부터 두 배 인상, 이전 2,300)
- 학생비자 거절률: 전체 평균 약 18% (2025), **한국은 Assessment Level 1로 일반적으로 더 낮음**
  - 단, 2026년 호주 정부의 강화된 GS 심사로 거절률 변동 가능성 있음
  - 인도·네팔·방글라데시는 40~65% (Level 3)
- 학생비자 근무: 격주 48시간 (학기 중), 방학 무제한 (Condition 8105)
- OSHC: 연 500-700 AUD
- 연간 거주비 증빙: 29,710 AUD

### 호주 생활
- 최저시급: 24.95 AUD (2024.7~)

### PR 관련
- **485 비자**: 만 35세 이하 (2024.7~, Master by Research/PhD/HK 여권은 50세까지)
- **485 기간**: 학사·석사 코스워크 2년 / 석사 리서치·PhD 3년 + 지방 보너스 1~2년
- **485 영어 기준**: IELTS 6.5 (각 5.5 이상, 2024.3~ 인상)
- Greater Brisbane: 2024년부터 PR 지방 분류 제외
- Greater Perth: 2022년부터 지방 분류 (PR +5점)
- TAS / SA 전체: 가장 후한 PR 지방
- 골드코스트 / 케언즈 / 타운스빌: 지방 분류 유지
- ⚠️ **회계 PY 폐지: 2025.3.31 신규 등록 중단, 2026.5.1 완전 종료**
  - IT PY, Engineering PY는 계속 운영
  - 회계 PR 시 PY +5점 옵션 사라짐 → 지방 491 트랙 강력 추천
- ⚠️ **유아교육 교사(ECT) 직업평가 기관 변경: 2024.12.7부터 AITSL → ACECQA**
  - 초·중등 교사는 여전히 AITSL
  - 유아교육은 ACECQA (0~5세 기준 더 엄격)
- ⚠️ **AHPRA 영어 기준 변경 (2025.4.18~)**: IELTS 7.0 (L/R/S 7.0, **W 6.5 가능**) — Writing만 완화
  - OET는 새 점수제 (350~360, 이전 B 등급)

### GS (Genuine Student) — 2024.3.23 변경
- 이전 GTE 자기소개서 폐지
- 4가지 정형 질문 + 1가지 추가 질문 (워홀러/비자 전환자) 각 150단어
- ImmiAccount 온라인 폼에 직접 입력 (별도 첨부 비추천)
- 자세한 가이드: `05_비자PR_모듈/04_GS_답변_가이드.md`

### 학생 노출 카드 (외부) — 7장 구성
- **카드당 200~300자** (호기심 격차 + 마케팅)
- **사이트 링크 X** (Ausuhak 안에 잡아두기)
- **연봉은 사이트 이름만** (PayScale / SEEK Salary Guide / Glassdoor)
