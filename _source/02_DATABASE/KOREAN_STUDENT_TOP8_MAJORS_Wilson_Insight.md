## 1_의대 (Medicine)

| 항목 | 내용 |
|---|---|
| 공식 코스 | Doctor of Medicine (MD) — 4년 graduate-entry 표준 |
| 학비 (2026) | $76,000~$112,000/년 (international) |
| IELTS | 7.0 (각 7.0) — AHPRA 표준 |
| PR 직군 | MLTSSL — General Practitioner 253111 / Resident Medical Officer 253112 |

**Top 학교**:
- **Direct Entry (school-leaver)**: Monash, UNSW, Adelaide University, Newcastle JMP
- **Graduate Entry (학사 후)**: Melbourne, Sydney, ANU, Deakin, UQ, UWA

**Wilson Insight**: 한국 학생 의대 진학 = 호주 학사 (Bachelor of Biomedicine/Medical Science) → GAMSAT → 4년 MD가 가장 일반적. 경쟁률 매우 치열. 직접 진학 (UNSW/Monash/Adelaide) = ATAR 99+ 또는 Foundation 1년 통한 경쟁. International 학비 7년 총 $500K+ 예상.

⚠️ **주의**: ⚠️ MD 졸업 후에도 호주 PR 직접 안 됨. AHPRA 등록 + Internship 1년 + Resident Medical Officer 트랙. 졸업 → 485 → 영주권은 5~7년 더 걸림.

| 학비 (2026) | $45,000~$60,000/년 |

| PR 직군 | ⚠️ MLTSSL Direct 직업평가 X. Medical Lab Scientist 234611 (석사 + 인증 필요) 또는 의대/약대 진학 pathway로 사용 |

**Top 학교**:
- **G8**: UMelb (Bachelor of Biomedicine), Monash, UQ, UNSW, USyd, UWA, Adelaide
- **비-G8**: UTS, Bond, ACU, VU

**Wilson Insight**: 생명공학 학사 자체로 PR 직접 안 됨. 한국 학생 활용법 = (1) MD/약대 graduate-entry pathway, (2) Master of Medical Lab Science (Griffith/QUT/RMIT) → Lab Scientist 234611 직업평가, (3) 한국 귀국 후 제약/바이오 R&D.

⚠️ **주의**: ⚠️ 졸업 후 호주 취업 어려움 (실험실 PhD 트랙 외). PR 목적이면 추천하지 않음. 의대/약대 진학 pathway로만 의미.

## 3_약대 (Pharmacy)

| 항목 | 내용 |
|---|---|
| 공식 코스 | Master of Pharmacy (graduate-entry, 2년) / Bachelor of Pharmacy (4년) |
| 학비 (2026) | $50,000~$60,000/년 |
| IELTS | 7.0 (각 7.0) — AHPRA 표준 |
| PR 직군 | MLTSSL — Hospital Pharmacist 251511 / Retail Pharmacist 251513 |

**Top 학교**:
- **Master of Pharmacy**: USyd, Monash, UQ
- **Bachelor of Pharmacy**: USyd, Monash, UQ, UWA, Curtin, RMIT, Griffith

**Wilson Insight**: 한국 학생 약대 = 호주 졸업 후 1년 Internship → AHPRA 등록 → PR 가능 (MLTSSL 등재 직군). Master of Pharmacy graduate-entry (2년)이 학사 4년보다 효율적. 단 Master Pharmacy 운영 학교 적음 (USyd/Monash/UQ만).

⚠️ **주의**: ⚠️ AHPRA 영어 IELTS 7.0 (Listening/Reading/Speaking 7.0, Writing 6.5 가능 — 2025.4.18~ 변경). Internship 1년 호주 약국 + 시험 통과 후 등록.

## 4_IT (Information Technology)

| 항목 | 내용 |

| 학비 (2026) | $41,000~$59,500/년 (Master 기준, 학교별) |
| IELTS | 6.5 (각 6.0) — ACS 표준 |
| PR 직군 | MLTSSL — Software Engineer 261313, ICT BA 261111, Cyber Security 262112, Data Scientist 224711, Network Engineer 263111 |

**Top 학교**:
- **O-2 그룹 (이미 검증)**: UTS / RMIT / Monash / UNSW / USyd / Macquarie / QUT / Deakin
- **추가**: ANU, UWA (Go8), UoW (Cat 2 +5/+15), Curtin (Cat 2), Adelaide (Cat 2)

**Wilson Insight**: 한국 학생 PR 트랙 1순위 분야. ⚠️ PY (Professional Year) IT는 계속 운영 (회계와 다름). 지방 학교 (UoW Cat 2 / Adelaide Cat 2) 졸업 → 491 트랙 강세. Cyber Security/AI 가장 인기.

⚠️ **주의**: ✅ PY IT는 2026 현재 살아있음 (회계 PY는 2026.5.1 종료와 다름). ACS 직업평가 통과 + 1~3년 호주 직장 경력 필요.

| IELTS | 6.5 (각 6.0) / MBA는 7.0+ 권장 |
| PR 직군 | ⚠️ Business 일반 = MLTSSL Direct 직업평가 X. 단 회계 (Accounting 221111) / Management Consultant (224711) / Marketing Specialist (225113) = MLTSSL 가능 |

**Top 학교**:
- **AACSB+EQUIS+AMBA Triple Crown**: UNSW (AGSM), Monash, USyd, Macquarie, Melbourne (MBS), QUT, UQ
- **한국 학생 인기**: Macquarie (10x), Adelaide (7x), UTS (7x), RMIT (7x), Curtin (7x)

**Wilson Insight**: 한국 학생 가장 인기 분야. 단 PR 목적이면 회계 (Accounting major) 또는 Marketing Specialist/Mgmt Consultant 직군으로 specialise 필요. MBA 자체는 PR 직업평가 X. 한국 귀국 후 외국계/대기업 취업 목적 강세.

⚠️ **주의**: ⚠️ Business 학위 졸업 후 PR = 회계 요건 충족 또는 specialise 직군 (224711 등) 필요. MBA만으로 PR 안 됨.

|---|---|

| 학비 (2026) | $22,000~$52,990/년 |
| IELTS | 6.5 (각 6.0) |
| PR 직군 | MLTSSL — Accountant General 221111 / Auditor 221213 |

**Top 학교**:
- **저비용 지방**: Holmes Institute (Cairns Cat 3 / Gold Coast Cat 2)

**Wilson Insight**: 한국 학생 회계 PR 트랙 = Master of Pro Accounting → CPA Australia 회원 → 직업평가 → PR. ⚠️ PY (Professional Year) 회계 2026.5.1 완전 종료 → 지방 학교 (Cat 2/Cat 3) 491 트랙 필수.

⚠️ **주의**: ⚠️ PY 회계 2026.5.1 완전 종료. Accounting PR 점수 매우 높음 (95~100점). 지방 491 트랙 (Cat 2/Cat 3) 강세.
