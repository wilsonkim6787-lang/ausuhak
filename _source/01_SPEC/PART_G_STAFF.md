# 🎯 PART G. 직원 페이지 (/staff)

> **접근 권한**: Wilson이 직원으로 등록한 사용자
> **URL**: `/staff/*`
> **권한 범위**: Wilson이 부여한 권한만 (PART C-2 체크박스 17개)
> **담당 학생**: `student_assignments` 테이블 (주담당 / 공유 담당 / 관찰 담당)

## G-1. 핵심 원칙

```
✅ 직원 페이지 = 본인 담당 학생만 보기 (기본값)
✅ Wilson 권한 부여 시 → 추가 권한 활성화
✅ 모든 행동 = activity_logs 자동 기록
✅ 무단 접근 시도 = 자동 차단 + Wilson 알림
✅ 다른 직원 KPI 노출 X (협업 원칙 / leaderboard X)

❌ 절대 X:
   - 🔴 Wilson 전용 메모 (visibility='wilson_only')
   - 다른 직원의 담당 학생 데이터 (담당 외)
   - admin URL (/admin/*)
   - 학생 internal_data / wilson_note 필드
   - 다른 직원의 활동 로그
```

## G-10. 직원 활동 로그 (자동 기록 / Wilson 검토)

### 모든 직원 행동 = activity_logs 자동 기록

```
직원이 한 행동 자동 기록:
   ✅ 학생 데이터 보기 (view_student)
   ✅ 메모 작성 (write_note)
   ✅ Stage 변경 (update_stage)
   ✅ 카톡 발송 (send_kakao_alert)
   ✅ 서류 검증 (verify_document)
   ✅ 견적서 작성 (create_quote)
   
무단 시도 = 자동 차단 + Wilson 알림:
   🚨 본인 담당 외 학생 접근
   🚨 🔴 Wilson 전용 메모 접근
   🚨 다른 직원 KPI 조회
   🚨 admin URL 접근
```
