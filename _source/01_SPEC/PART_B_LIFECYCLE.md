# 🎯 PART B. 학생 라이프사이클 + Lead Status

## B-1. 학생 라이프사이클 = 12단계 (일반·의대 동일)

> **핵심 원칙**: 의대 학생도 일반 학생과 똑같은 12단계 적용.
> 의대는 **Stage 자체가 다른 게 아니라**, **Stage 7 (학교 지원) 안의 내용이 더 복잡할 뿐**.

```
═══════════════════════════════════════════════════
🆓 무료 단계 (회원가입 X / 익명)
═══════════════════════════════════════════════════

[사이트 진입]
   ├─ A) 메인 → 6변수 진단 → 카드 7장
   ├─ B) 메인 → /medical 정보 페이지 → 무료 체험
   └─ C) 카카오 채널 직접 진입
   ↓
[localStorage 익명 ID]
   ↓
[카톡 채널 클릭]
   pf.kakao.com/_GadTX
   ↓
═══════════════════════════════════════════════════

Stage 1   카톡 1차 상담 30분 (무료 / 일반·의대 동일)
   ├─ 일반 학생 → Wilson 또는 직원 (자동 분배 4단계)
   ├─ 의대 학생 → Wilson 직접 (위임 X)
   ├─ Lead 캡처: 이름·카톡 (가벼움)
   ├─ 학생 6변수 + 카드 결과 자동 전달
   ├─ Wilson Alerts 자동 체크
   └─ 30분 후 → 결제 권유 (Wilson 케이스 판단)

═══════════════════════════════════════════════════
💎 유료 단계 (결제 = 자동 회원가입)
═══════════════════════════════════════════════════

Stage 2   결제 (payment_type 필드로 구분)
   ├─ 일반: PRO ₩50,000 / 풀 컨설팅
   ├─ 의대: 의대 ₩300,000 / 풀 컨설팅
   └─ 결제 시 = 자동 회원가입 + 마이페이지 활성화

Stage 3   1:1 상담 (Wilson 직접)
   ├─ PRO = 1:1 상담 2시간 (줌 OR 방문)
   ├─ 의대 = ISAT 200 + MMI 40 학습 시작 + Wilson 피드백
   ├─ 풀 컨설팅 = 무제한 (5~7회 + 입학 후 케어)
   └─ ⭐ 견적서 만들기 (관리자 페이지)
       - 학교 1~3개 선택 (일반 또는 의대 학교)
       - PDF 자동 생성 → 학생 카톡 발송 + 마이페이지 저장

Stage 4   학교 선정 + 다중 지원 (3~5개 동시)
   ├─ 일반: 일반 학교 3~5개
   └─ 의대: 의대 학교 3~5개

Stage 5   영어 준비
   ├─ 일반: IELTS 6.0~6.5
   └─ 의대: IELTS 7.0+ (의대 표준)

Stage 6   학생 서류 수집
   ├─ 일반: 여권 / 학력 / 영어 / 재정 / GS
   └─ 의대: 위 + 추천서 / Personal Statement

Stage 7   학교 지원 (Application) ⭐ 의대만 더 복잡
   ├─ 일반: Application 제출 + GS 답변
   └─ 의대: Application + ISAT + MMI 인터뷰 + (필요시) GAMSAT/GEMSAS

Stage 8   Offer Letter 받음 ⭐
   ├─ 일반: 1차 합격
   └─ 의대: 1차 합격 (MMI 인터뷰 통과 후)

Stage 9   학비 송금 + CoE 발급

Stage 10  학생비자 500 신청

Stage 11  출국 준비 + 출국

Stage 12  호주 도착 + 학업
   ├─ 일반: 1주 / 1개월 / 3개월 / 6개월 체크인
   └─ 의대: 위 + 첫 임상 실습 / 시험 시즌 별도 체크인
   ↓ (졸업 후)
🎓 졸업생 DB 자동 이동 (PR 후기·통계·후기 자산용)
```

## B-3. Lead Status 7단계 (CRM·통계용 / Stage와 별개)

```
Lead       익명 진단 中 (localStorage)
              - 카드 7장 결과 페이지 도달
              - /medical 무료 체험
              - 카톡 클릭 X

Contacted  카톡 1차 상담 클릭
              - 이름·카톡 캡처
              - Stage 1 진입

PRO        결제 완료 (50K 또는 300K)
              - 일반 학생 = PRO ₩50,000
              - 의대 학생 = 의대 ₩300,000

Contract   풀 컨설팅 계약
              - 일반 또는 의대 풀 컨설팅
              - PRO/의대 결제 후 업그레이드 포함

Visa       비자 신청 진행 中 (Stage 10)

Onsite     호주 도착·학업 中 (Stage 12)

PR         영주권 취득
              - 졸업생 DB로 이동
```

### Stage 12단계 vs Lead Status 7단계 매핑

| Lead Status | Stage 위치 | 비고 |
|---|---|---|
| Lead | (사이트 익명 진단 / /medical 무료) | 카톡 클릭 전 |
| Contacted | Stage 1 | 카톡 1차 상담 |
| PRO | Stage 2 (payment_type='pro' 또는 'medical') | 결제 완료 |
| Contract | Stage 2 (payment_type='full') | 풀 컨설팅 |
| Visa | Stage 10 | 비자 신청 |
| Onsite | Stage 12 | 호주 학업 中 |
| PR | (졸업생 DB) | 영주권 |

### 통계 활용
- 깔때기 전환율: Lead → Contacted → PRO → Contract → Visa → Onsite → PR
- 각 단계별 이탈률 분석 → 사이트 개선
- 일반 vs 의대 분리 통계 (is_medical flag)
- Wilson 관리자 페이지 통계 대시보드에 표시

## B-4. 의대 학생 분류 + Stage 7 차이점

### 의대 자동 분류 룰

```
[학생이 카톡 채널 진입]
        ↓
[챗봇 6변수 수집]
        ↓
   ┌────────────────────────────────┐
   │ 의대 자동 분류:                   │
   │                                │
   │ IF 6변수.전공 = "의료"           │
   │   OR 진입 경로 = /medical        │
   │   OR 카톡에 "의대" 키워드        │
   │ → is_medical = true            │
   │ → Wilson 직접 응대 (위임 X)     │
   │                                │
   │ ELSE                           │
   │ → is_medical = false           │
   │ → 직원 자동 분배 가능           │
   └────────────────────────────────┘
        ↓
[Stage 1 시작 = 일반·의대 동일 (12단계)]
```

### Stage 7 (학교 지원) — 의대만 추가 항목

**일반 학생 Stage 7:**
```
1. Application 제출 (3~5개 학교)
2. GS Statement 작성 (4개 정형 질문)
3. 학교별 합격 통지 대기
```

**의대 학생 Stage 7 (추가):**
```
1. Application 제출 (3~5개 의대)
2. GS Statement 작성
3. ISAT 시험 응시 (UNSW / Adelaide)
4. GAMSAT 응시 (Graduate Entry MD인 경우)
5. GEMSAS 지원 (해당 시)
6. MMI 인터뷰 일정 잡기
7. MMI 인터뷰 응시
8. 학교별 합격 통지 대기
```

→ **Stage 7 안의 단계는 더 많지만, Stage 자체는 동일하게 7번**.

### 의대 5진학루트 (master_v2 또는 별도 데이터)

```
1. direct      Year 12 / IB / 수능 직접 지원 (5~6년)
2. undergrad   호주 학사 후 Graduate Entry MD (7~8년)
3. graduate    학사 + MCAT (해외 의대)
4. converter   한국 의사 → AMC 시험 (호주 면허 전환)
5. transfer    한국 의대 재학생 → 호주 의대 재지원
```

→ Wilson이 Stage 1 카톡 상담에서 학생 학력에 맞는 1~2개 안내.

## B-6. 학생 자동 케어 시스템 (정체 감지)

| 트리거 | 액션 |
|---|---|
| 학생 5일+ 활동 X | Wilson 알림 |
| 마이페이지 1주+ 미접속 | 학생 카톡 자동 |
| 서류 업로드 3일+ 지연 | 학생 카톡 |
| 결제 후 5일+ 다음 액션 X | Wilson 알림 |
| 비자 신청 후 30일+ | 학생 자동: "심사 평균 4~8주, 안심하세요" |
| Stage 정체 (같은 Stage 14일+) | Wilson 긴급 알림 |
| 호주 도착 후 6개월 | Failure Pattern 6개 자동 체크 |
| 의대 ISAT 학습 7일+ 미진행 | Wilson 알림 |
| 의대 MMI 모범답안 14일+ 미열람 | Wilson 알림 |

## B-7. 6 Failure Patterns (Wilson 19년)

```
1. 부모-자녀 소통 실패 (한국 비교 양육 → 갈등)
2. 아르바이트 과몰입 (학업 지장)
3. 실용 영어 부족 (시험 점수와 별개)
4. 과도한 용돈 → 여가 과몰입
5. 부모의 학생 약점 평가 불신 (Wilson 진단 무시)
6. 한인 하우스메이트 의존 (호주 적응 실패)

→ 학생 메모장 / 정기 체크인 / 알림톡 응답 패턴 분석
→ AI 자동 감지 → Wilson 알림 (학생/직원 X)
```
