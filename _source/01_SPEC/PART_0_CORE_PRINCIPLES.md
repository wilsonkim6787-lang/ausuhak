### 작동 방식
```
[학생 6변수 입력]
        ↓
[Step 1: 시나리오 매칭]
   FAQ 36개 시나리오 中 1개 (룰 기반 매칭)
   매칭 키 = 학력 + 영어 + 전공 (3개 핵심)
        ↓
[Step 2: 모듈 조합]
   시나리오가 명시한 모듈 호출:
   - 학교 모듈 1~3개 (24개 中)
   - 지역 모듈 1개 (8개 中)
   - 전공 모듈 1개 (10개 中)
   - 비자/PR 모듈 1~3개 (5개 中)
        ↓
[Step 3: 카드 7장 자동 조립]
   각 모듈의 PUBLIC 영역만 추출 → 7장 슬롯 분배
        ↓
[Step 4: 차단룰 자동 체크]
   master_v2.json 차단룰 + Wilson Alerts 검증
        ↓
[Step 5: 학생용 콘텐츠만 노출]
   INTERNAL 영역 = 직원 페이지에서만
```

### 절대 금지
- AI가 즉석에서 학교 추천 X
- AI가 즉석에서 학비 계산 X
- 시나리오 매칭 안 되면 → 가장 가까운 시나리오 + Wilson 카톡 유도 (절대 추측 X)

## 0-15. 견적서 = 관리자 페이지에서 Wilson 생성

### 절대 원칙
- ❌ 학생이 직접 견적서 생성 X
- ✅ Wilson이 카톡 상담 후 관리자 페이지에서 생성 → 학생에게 전달

### 견적서 자동 항목 (8개)
1. 학비 (학교별 / master_v2 데이터 / 학생 선택 1~3개)
2. 생활비 (지역별 / 월·연 환산)
3. 학생비자 500 신청비 ($2,000 / 정부 정책 변경 시 자동 업데이트)
4. OSHC ($500~700/년)
5. 항공권 (편도/왕복)
6. 정착비 (보증금·교재·가구)
7. Wilson 컨설팅비 ₩50,000 (진학 시 100% 차감 표시)
8. 한화 환산 (실시간 환율)

### 절대 X
- ❌ 알바비 차감
- ❌ 485 졸업비자 신청비 (학생비자 500만)
- ❌ 동반자 비자 (배우자/자녀/가디언 590)
- ❌ 비자 대행료 (에이전시 fee)
- ❌ 학생이 직접 견적서 만들기

### 학교 1~3개 선택 (Wilson이 학생 상황 보고 결정)
- 1개만 → 단일 견적서
- 2~3개 → 비교 견적서 (가로 비교 표 + 항목별 차이)

### 출력
- PDF 자동 생성
- 학생 카톡 발송 OR 학생 마이페이지 저장
- Wilson 1-click 수정 가능
- 진행 중 견적서 = snapshot 보존 (정책 변경 영향 X)
