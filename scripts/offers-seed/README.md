# 합격증 갤러리 시드 (2026-08)

2026년 7~8월 배치 대학 오퍼레터 15건 — 개인정보(이름·생년월일·학생번호·주소·연락처·여권·에이전트) 모자이크 처리 완료본.

- `images/` — 마스킹된 오퍼 이미지 15장 (오퍼당 1장, 표지 제외)
- `offers.json` — 학교·과정·연도·학생 이니셜·노출 순서·후기(markdown)

후기는 각 오퍼레터에 적힌 사실(학교·과정·기간·조건)에 기반해 학생 관점으로 쓴 **초안**이다.
업로드 시 전부 `draft` 상태로 들어가므로, `/admin/offers` 에서 검토·수정 후 공개(published)로 전환한다.

실행:

```bash
node --env-file=.env.local scripts/upload_offers.mjs
```
